# 要件定義: Gmail + iCloud 未読通知 Chrome拡張

## 1. 目的
Gmail（複数アカウント）と iCloud メール（1アカウント）の未読状況を、Chrome のツールバーからまとめて確認できるようにする。新着メールはデスクトップ通知で知らせる。

参考にした拡張:
- Checker Plus for Gmail
- iCloud Mail Notifier

## 2. 前提・制約
| 項目 | 内容 |
|---|---|
| 利用者 | 開発者本人のみ。ストア公開はせず、unpacked で読み込む |
| プラットフォーム | Chrome（Manifest V3） |
| 実装 | TypeScript + Vite |
| Gmail の認証 | ブラウザでログイン済みのセッション Cookie を使う。OAuth は使わない |
| iCloud の認証 | icloud.com にログイン済みのセッション Cookie を使う |
| 外部仕様 | Gmail の Atom フィードは Cookie 経由での利用が公式に文書化されていない。iCloud の API は非公開。どちらも提供元の変更で動かなくなる可能性があり、その前提を受け入れる |

## 3. 機能要件

### FR-1 ツールバーアイコン
- FR-1.1 ツールバーにメールのアイコンを表示する。
- FR-1.2 全アカウントの未読数の合計をバッジに表示する。合計が 0 のときはバッジを表示しない。
- FR-1.3 サインアウト中やエラーのアカウントが1つでもあれば、バッジの色を変えて知らせる。数字は合計のまま表示する。

### FR-2 未読数の取得
- FR-2.1 Gmail は、ブラウザでログインしているすべてのアカウントを自動で検出する。上限は 10 アカウント。
- FR-2.2 Gmail は、アカウントごとに受信トレイの未読数と未読メールを取得する。
- FR-2.3 iCloud は、ログイン中の 1 アカウントについて受信箱の未読数と未読メールを取得する。
- FR-2.4 一定間隔で自動チェックする。初期値は 1 分、最小は 30 秒で、設定で変更できる。
- FR-2.5 ブラウザ起動時、拡張インストール時、ポップアップを開いたときにも即時チェックする。

### FR-3 未読メール一覧（ポップアップ）
- FR-3.1 アイコンをクリックすると未読メールの一覧を表示する。
- FR-3.2 一覧はアカウントごとにまとめる。見出しにはメールアドレスと未読数を出す。
- FR-3.3 各行には差出人、件名、本文の冒頭（抜粋）、日時を表示する。
- FR-3.4 サインアウト中のアカウントには「ログインしてください」と表示し、ログインページへのリンクを置く。
- FR-3.5 「今すぐ更新」ボタンと、設定画面へのリンクを置く。

### FR-4 メールを開く
- FR-4.1 Gmail の行をクリックすると、該当アカウントでそのメールを新しいタブに開く。
- FR-4.2 iCloud の行をクリックすると、icloud.com の受信箱を新しいタブに開く。iCloud には個別メールを直接開く URL が無いため。

### FR-5 新着通知
- FR-5.1 前回のチェック後に届いた未読メールを検出したら、デスクトップ通知を出す。
- FR-5.2 新着が 1 件なら差出人と件名を表示する。複数件なら「N 件の新着メール」と先頭の件名を表示する。
- FR-5.3 通知をクリックすると、FR-4 と同じ規則でメールを開く。
- FR-5.4 拡張の初回チェック時と、新しいアカウントを検出したときは通知しない。
- FR-5.5 通知は設定で ON/OFF できる。

### FR-6 設定画面
- FR-6.1 チェック間隔を設定できる。
- FR-6.2 通知の ON/OFF を設定できる。
- FR-6.3 Gmail と iCloud のそれぞれについて、有効/無効を設定できる。
- FR-6.4 設定は chrome.storage.sync に保存し、変更はすぐに反映する。

## 4. 非機能要件
- NFR-1 エラーを握りつぶさない。取得に失敗したアカウントは、状態とエラーメッセージを一覧に出す。フォールバック値で隠さない。
- NFR-2 TypeScript で `any`、`unknown`、`class` を使わない。外部 API の応答はスキーマで検証する。
- NFR-3 プロバイダ（Gmail、iCloud）ごとにモジュールを分け、片方が壊れてももう片方は動き続けるようにする。
- NFR-4 typecheck、lint、ユニットテスト（パーサ、新着の差分検出）が通る。
- NFR-5 iCloud のヘッダー書き換えは、自拡張が発行するリクエストだけに限定する。

## 5. 対象外
- 既読化、アーカイブ、削除などのメール操作
- メール本文の拡張内表示
- iCloud の複数アカウント
- Gmail の受信トレイ以外のラベルの監視
- OAuth 認証、Chrome ウェブストアへの公開

## 6. 受け入れ基準
1. Gmail の複数アカウントにログインした状態で、バッジの合計と一覧が各アカウントの Gmail 画面の未読と一致する。
2. Gmail の行をクリックすると、正しいアカウントで該当メールが開く。
3. icloud.com にログインした状態で、iCloud の未読が一覧に表示される。行をクリックすると受信箱が開く。
4. テストメールを送ると、設定した間隔（1 分）の範囲内で通知が出る。通知をクリックすると FR-4 どおりに開く。
5. icloud.com からログアウトすると、iCloud のセクションが「ログインしてください」の表示になり、バッジの色が変わる。
